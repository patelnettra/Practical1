# Semantic HTML5 Webpage Project

## 1. Project Objective

The objective of this project is to design and develop semantic
HTML5 webpages using meaningful HTML elements such as header, nav,
main, section, article, address, and footer.

The project demonstrates how semantic HTML improves the structure,
readability, accessibility, and maintainability of a webpage.

---

## 2. Project Description

This project contains two semantic webpages:

1. College Department Homepage
2. NGO Information Webpage

The College Department webpage contains information about:
- About the Department
- Faculty
- Academic Programs
- Events
- Contact Information

The NGO webpage contains information about:
- Mission
- Ongoing Projects
- Volunteer Opportunities
- Donation Details
- Contact Information
